# SEG-Y Inspector v3

Adds a Trace Inspector dock to the SEG-Y viewer.

## Features
- Trace navigation
- `Byte | Field | Value` trace-header table
- Search/filter
- Inline, Crossline, CDP and Offset summary
- Click seismic preview to select a trace
- Textual header formatted with `segyio.tools.wrap`

## Run
```powershell
pip install -r requirements.txt
python main.py
```
